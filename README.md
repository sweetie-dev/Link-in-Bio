# Site para Empresa Icaros lembraças — Link in Bio

> Página de links desenvolvida para reunir, em um único lugar, os principais canais digitais da Ícaros Lembranças.

## Sobre o projeto

Este projeto foi desenvolvido durante minha experiência na empresa **Ícaros Lembranças**, com o objetivo de criar uma página simples, organizada e visualmente alinhada à identidade da empresa.

A proposta era facilitar o acesso dos clientes aos principais canais da marca, reunindo links importantes em uma única página.

##  Funcionalidades

- Links para os principais canais da empresa
- Acesso rápido às redes sociais
- Botões organizados e de fácil navegação
- Layout responsivo para celular e computador
- Identidade visual personalizada para a marca

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript

## 🎯 Objetivo

Criar uma experiência simples e direta para que os clientes encontrassem facilmente os principais canais de contato e divulgação da Ícaros Lembranças.
